# JEE Aspirant Portfolio

A personal portfolio website for a JEE aspirant student. Built with HTML5 and CSS3.

## Features

- **Responsive Design**: Works on mobile and desktop
- **Fixed Navigation**: Always accessible at the top
- **Three Sections**:
  - Home: Introduction with animated gradient background
  - About: Student background, goals, and focus areas
  - Contact: Email and phone links
- **Card Grid**: Three feature cards about education, goals, and focus
- **Mobile-First**: Adapts to screens below 700px

## Structure

```
index.html    - Main HTML structure
style.css     - All styling and responsive design
```

## Customization

- Update contact information in `index.html`
- Modify colors in `style.css` (gradient colors, background colors)
- Change font or layout as needed

## Browser Compatibility

Works in all modern browsers (Chrome, Firefox, Safari, Edge).
